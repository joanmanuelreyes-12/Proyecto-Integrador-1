# Biblioteca escolar con ejemplares irregulares


## Objetivo
Desarrollar un sistema para administrar una biblioteca escolar con diferentes cantidades de ejemplares por título.

El sistema permitirá consultar disponibilidad, registrar préstamos, ordenar el catálogo y buscar libros por ISBN.

## Estructura del repositorio
- docs/: documentos del proyecto.
- README.md: información general.
- .gitignore: archivos que Git debe ignorar.
